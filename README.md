Question 2: HTML Elements
1. Which 5 elements did you find most challenging to implement and why?

The five elements I found most challenging to implement were:

<table> – It was challenging because it requires several elements such as <tr>, <th>, and <td> to organize information correctly.
<form> – It was challenging because I had to combine different form controls, labels, and input fields correctly.
<fieldset> – I had to understand how to use it to group related form controls together.
<details> – This was challenging because I had to understand how it works together with the <summary> element to create expandable information.
<figure> – I used it together with <figcaption> to organize an illustration and its description.
2. How did you use semantic elements like <section>, <article>, <header>, and <footer>?

I used the <header> element for the top part of my website, where I placed my name, course information and navigation menu.

I used <section> to divide the main content into different areas such as About Me, Education, Courses, Skills, Goals and Contact. The <article> element was used for individual pieces of information within sections.

Finally, I used the <footer> element at the bottom of the website to contain copyright information and a link back to the top of the page. This semantic structure makes the content properly organized and easier to understand.

3. Which element was most useful for organizing your layout and why?

The <section> element was the most useful because it allowed me to divide my website into clear and meaningful parts. Each section has a specific purpose, making the website easier to navigate and understand.

Question 3: HTML Attributes
1. Which 3 attributes were essential for making your website functional?

The three most important attributes were:

href – Used to connect navigation links to different sections of the webpage.
id – Used to give sections unique identifiers so that navigation links can target them.
action – Used with the form to specify where the form information would be sent.

Other attributes I used include class, name, type, placeholder, required, for, value, rows, cols, scope, datetime, title, aria-label, role, cite, method, lang, charset, and content.

2. How did you use the class and id attributes differently?

I used the id attribute to uniquely identify specific elements or sections of my website. For example, I used IDs such as about, education, courses, and contact. These IDs were also used by navigation links.

I used the class attribute to group elements that have similar purposes. For example, several sections use the content-section class. Unlike an ID, a class can be used on multiple elements.

3. Which attribute helped improve user experience the most and why?

The title attribute helped improve the user experience because it provides additional information when a user interacts with navigation links. I also used the aria-label attribute to provide meaningful descriptions for accessibility.
